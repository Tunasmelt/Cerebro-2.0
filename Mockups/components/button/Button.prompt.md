Clickable action. Use primary for the single main call to action on a screen, secondary for teal confirmatory actions, ghost for low-emphasis toolbar/inline actions, danger for destructive actions like deleting a note or purging a vault.

```jsx
<Button variant="primary">New capture</Button>
<Button variant="secondary">Save changes</Button>
<Button variant="ghost">Cancel</Button>
<Button variant="danger">Delete permanently</Button>
```

Set `disabled` to show the disabled state. `size="sm"` for dense toolbars.
